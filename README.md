# Как опубликовать сайт

## 1. Отредактируй тексты

Открой `index.html` в любом текстовом редакторе (подойдёт даже Блокнот, но лучше
[VS Code](https://code.visualstudio.com/) — бесплатно). Замени:

- «Имя Фамилия» — на своё имя или псевдоним (во всех местах, поиском Ctrl+F)
- Заголовки проектов «Название проекта»
- Описания «[список]», «[роль]» и текст-заглушки в `<p class="case__desc">`
- `you@example.com` — на свою почту
- `https://t.me/yourusername` — на свой Telegram

## 2. Добавь видео и картинки

- Закинь сжатые .mp4 в папку `videos/` с именами `reel.mp4`, `work-1.mp4` … `work-5.mp4`
  (подробности — в файле `videos/ПОЛОЖИ_СЮДА_ВИДЕО.txt`)
- Если ещё не все 5 роликов сжаты — ничего страшного, можно опубликовать сайт
  с тремя и добавить остальные позже (см. шаг 5, «обновление сайта»)
- По желанию — постеры в `images/` (см. `images/ПОЛОЖИ_СЮДА_КАРТИНКИ.txt`)
- Если хочешь кнопку с резюме — положи `resume.pdf` рядом с `index.html`

## 3. Залей проект на GitHub

1. Зайди на github.com → нажми **"+"** в правом верхнем углу → **"New repository"**
2. Название репозитория: например `portfolio` (латиницей, без пробелов)
3. Оставь **Public**, ничего больше не отмечай → **"Create repository"**
4. На следующей странице найди ссылку **"uploading an existing file"**
   (или кнопку **"Add file" → "Upload files"**)
5. Перетащи туда ВСЮ папку `portfolio` целиком (index.html, style.css, script.js,
   папки videos и images со всем содержимым)
6. Внизу нажми **"Commit changes"**

Если браузер не даёт загрузить видео весом больше ~25 МБ через веб-интерфейс —
напиши мне, покажу способ через GitHub Desktop (программа, тоже бесплатно и без карты,
загружает файлы без ограничений веб-версии).

## 4. Подключи Netlify

1. Зайди на app.netlify.com (ты уже зарегистрирован через GitHub)
2. Нажми **"Add new site" → "Import an existing project"**
3. Выбери **"Deploy with GitHub"**
4. Найди в списке свой репозиторий `portfolio` и выбери его
5. Настройки оставь по умолчанию (ничего менять не нужно, это статичный сайт)
6. Нажми **"Deploy"**

Через 20-30 секунд сайт будет опубликован по адресу вида
`https://random-name-12345.netlify.app` — это уже рабочая ссылка, её можно
временно вставлять куда угодно.

## 5. Обновление сайта (когда досожмёшь оставшиеся видео)

Просто зайди в свой репозиторий на GitHub → перетащи новые файлы в папку `videos/`
(или `Add file → Upload files`) → Commit. Netlify сам пересоберёт и обновит сайт
за 20-30 секунд, ничего дополнительно нажимать не нужно.

## 6. Свой домен (когда будешь готов)

Когда купишь домен (например на Namecheap) — в Netlify: **Site settings → Domain
management → Add a domain** — там будет пошаговая инструкция, какие DNS-записи
прописать у регистратора домена. Это можно сделать в любой момент, сайт при этом
не сломается — просто адрес станет твой, а не `*.netlify.app`.
